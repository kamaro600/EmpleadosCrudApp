# CRUD EMPLEADOS NET - SQLSERVER
Este proyecto es un crud simple para manejo de empleados con NET8 Y SQLSERVER
## Features

- Administracion de empleados con campos de usuario, nombre , email y cargo.
- Aplicacion dockerizada

## Requisitos

- NET8
- DOCKER
- SQLSERVER

# Instrucciones

1. Clonar el repository:
   ```
   git clone https://github.com/kamaro600/EmpleadosCrudApp.git
   ```

3. Construir la aplicacion usando docker:
   ```
   docker-compose up --build
   ```

4. Accede a la aplicacion en `http://localhost:8080/`.
